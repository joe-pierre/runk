# Fichiers du projet Runk

## Guide utilisateur
- `guide.md` : guide complet d'installation, configuration, lancement local, test et déploiement en production (Android + iOS).

## Fichiers du workflow (pour Claude Code)
- `CLAUDE.md` : contexte du projet + prompt d'amorçage à lire en début de chaque session.
- `SPEC.md` : spécifications fonctionnelles et techniques complètes.
- `CONVENTIONS.md` : règles de codage (nommage, architecture, sécurité, tests).
- `TODO.md` : suivi des tâches par phases.
- `DECISIONS.md` : journal des décisions techniques et bugs résolus.
- `BUGS_AND_ROADMAP.md` : bugs corrigés et idées d'amélioration future.
- `CODE_SNAPSHOT.md` : snapshot de code (généré automatiquement, ne pas modifier manuellement).
- `TASK_PROMPTS.md` : instructions détaillées de chaque tâche de développement, avec critères d'acceptation.
